#### Добавлены модулиЖ
- `utils` - принимает на вход путь до JSON-файла и возвращает список словарей с данными о финансовых транзакциях
- `external_ap` - принимает на вход транзакцию и возвращает сумму транзакции (`amount`) в рублях, тип данных — `float`. Если транзакция была в `USD` или `EUR`, происходит обращение к внешнему API для получения текущего курса валют и конвертации суммы операции в рубли. Для конвертации валюты воспользуйтесь Exchange Rates Data API
